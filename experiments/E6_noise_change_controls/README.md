# E6 — Noise-change controls

## Scientific role

E6 is primarily a methodology-correction experiment. It addressed an early ambiguity in which changes in observed noise level were being interpreted too readily as changes in the underlying dynamics.

## Problem identified

Observation noise and process noise affect local Koopman/EDMD estimation differently.

A change in observation noise does **not** by itself imply that the latent dynamical operator has changed. In fact, when the underlying dynamics remain fixed, longer histories can become more useful because they average observation noise rather than introduce dynamical bias.

## Correction

The project separated:

- observation-noise changes;
- process-noise changes;
- genuine changes in the latent dynamics.

These regimes must not be collapsed into one generic notion of "nonstationarity".

## Verdict

**AUDIT / FIX.**

The original interpretation was rejected and the control logic was redesigned.

## Rule inherited by later experiments

Never treat an observed increase in spectral estimator instability as evidence of dynamical drift without checking whether the same effect can be generated by changing observation noise, finite-sample variance, spectral-gap loss, or estimator conditioning.

This rule later became central to the source-attribution question tested directly in EXP-009.

## What E6 does not establish

E6 does not provide a new noise-robust Koopman estimator or a general noise-separation theorem. Its contribution to the project is methodological: it removes a confound from the interpretation of spectral instability.
